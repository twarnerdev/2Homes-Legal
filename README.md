## About TwoHomes

TwoHomes is a co-parenting management app that helps separated or divorced parents:
- Manage custody schedules
- Track and split expenses
- Coordinate events and appointments
- Handle payment schedules
- Request and approve schedule swaps

Available on the iOS App Store.
